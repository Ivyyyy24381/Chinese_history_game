# 账号 · 积分 · 排行榜 — 配置指南 ACCOUNTS_SETUP

## 现在就能用的（无需任何配置）

游戏已内置完整的积分和排行榜功能，**不配置任何东西也能玩**，只是数据存在玩家自己的浏览器里（本地模式）。

### 计分规则（来自建议.docx，改规则编辑 `src/utils/scoring.js`）

| 关卡 | 得分 |
|---|---|
| 选择题（答题/事件问答）| 答对一题 +20 |
| 填诗 | 每空答对 +10 |
| 数字华容道 | 满分 100，每过 1 秒 −1 |
| 出逃 | 满分 50，每过 1 秒 −1，被抓一次额外 −10 |
| 图片找点 | 满分 50，每过 1 秒 −1 |

- 单次游玩每一关只计一次分（重玩同一事件不重复得分）
- 顶栏实时显示本局积分
- 走完人物一生 → 结算总分，自动提交排行榜
- 选人页右上角：登录/注册、🏆 排行榜

## 开启云端账号（邮箱注册 + 全网排行榜）

> ⚠️ **2026-01 更新**：LeanCloud 已于 2026 年 1 月 12 日停止新用户注册，2027 年 1 月 12 日彻底停服，不再可选。
> 代码里的云端逻辑全部集中在 `src/services/backend.js` 一个文件（约 100 行），换任何一家只需改这一个文件，UI 和积分系统不用动。

三个可行方案，按目标玩家选：

### 方案 A：腾讯云开发 CloudBase（玩家在国内 → 推荐）

- 国内访问快且稳；免费体验环境 3000 资源点/月（2026 年起每账号一个），个人版套餐也便宜
- 自带云数据库 + 短信/邮箱/匿名登录，能覆盖注册 + 排行榜
- **最大优点：以后做微信小程序/小游戏时无缝衔接**（微信云开发同一套体系，玩家用微信身份免注册登录）
- 需要腾讯云账号 + 实名认证
- 控制台：<https://tcb.cloud.tencent.com>

### 方案 B：Supabase（玩家在海外/校园网 → 推荐）

- 免费额度大（5 万月活以内不要钱），内置邮箱注册（Auth）+ Postgres 数据库，10 分钟接完
- 缺点：服务器在境外，中国大陆访问不稳定，不适合面向国内的推广活动

### 方案 C：自建 PocketBase（想完全自己掌控）

- 一个可执行文件 = 数据库 + 邮箱注册 + 管理后台，跑在任意小服务器上
- 国内轻量服务器约 ¥24–50/月，但域名要备案；运维自己负责

选定后把选择告诉开发者（或 Claude），改一个文件即可切换。未配置时游戏保持本地模式，一切功能正常。

### 手机号 / 微信登录（后置）

- **手机号短信登录**：LeanCloud 支持，但短信按条收费，且要申请签名备案。等有推广活动再开。
- **微信登录**：网页版微信登录需要「微信开放平台」企业资质认证（个人不行）。如果以后做微信小游戏，小游戏内是免费自动登录的（见下）。

## 微信小游戏改造评估

结论：**能做，但是一次不小的改造，建议放最后。**

- 微信小游戏**不支持 DOM/HTML**，只有 canvas。本游戏是 React + DOM 写的，不能直接搬进去，UI 层基本要重写（或引入 kbone/Taro 这类适配层，对游戏类支持一般）
- 小游戏也**不允许用 web-view 套壳**（小程序可以，游戏类目不行）
- 上线需要：微信注册小游戏账号、软著或版号相关审核（教育类目相对宽松）、服务器域名备案
- **划算的路径**：先用现在的网页版跑活动（微信里可直接转发网页链接，体验已经不错）；如果验证了需求，再立项小游戏版，届时账号可直接用微信 openid 免注册登录
