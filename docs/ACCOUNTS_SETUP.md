# 账号 · 积分 · 排行榜 — 配置指南 ACCOUNTS_SETUP

## 现在就能用的（无需任何配置）

游戏已内置完整的积分和排行榜功能，**不配置任何东西也能玩**，只是数据存在玩家自己的浏览器里（本地模式）。

### 计分规则（来自建议.docx，改规则编辑 `src/utils/scoring.js`）

| 关卡 | 得分 |
|---|---|
| 选择题（答题/事件问答）| 答对一题 +20 |
| 填诗 | 每空答对 +10 |
| 数字华容道 | 满分 100，每过 1 秒 −1 |
| 出逃 | 满分 50，每过 1 秒 −1，被抓一次额外 −10 |
| 图片找点 | 满分 50，每过 1 秒 −1 |

- 单次游玩每一关只计一次分（重玩同一事件不重复得分）
- 顶栏实时显示本局积分
- 走完人物一生 → 结算总分，自动提交排行榜
- 选人页右上角：登录/注册、🏆 排行榜

## 开启云端账号（邮箱注册 + 全网排行榜）— 腾讯云开发 CloudBase

> 本项目用**腾讯云开发 CloudBase**：国内访问快，免费体验环境 3000 资源点/月，以后做微信小程序可无缝衔接（微信登录免注册）。

配置步骤（约 20 分钟，需实名认证）：

1. 打开 <https://tcb.cloud.tencent.com>，用微信/QQ 注册腾讯云账号并完成个人实名认证
2. 创建环境：选**免费体验版**（每账号一个，3000 资源点/月）→ 记下**环境ID**（形如 `xxx-1a2b3c4d`）
3. 左侧「API Key 配置」→ 生成 **Publishable Key**
4. 两个值粘贴进 `src/config/cloudbase.js`：

```js
export const CLOUDBASE_CONFIG = {
  envId: "你的环境ID",
  publishableKey: "你的PublishableKey",
  region: "ap-shanghai",
};
```

5. 「数据库」→ 创建集合 `scores`，权限选**「所有用户可读，仅创建者可读写」**（排行榜大家都能看，分数只能自己提交，防刷榜）
6. 「身份认证」→「登录方式」：
   - **邮箱验证码**：不能直接勾选，要先配发件邮箱——点卡片上的「配置发件邮箱」→ 选「**开启邮件代发**」（CloudBase 内置邮件服务，零配置）→ 保存，立即生效。**不需要**自己配 SMTP/QQ邮箱授权码，更不需要 Cloudflare
   - **匿名登录**：确认开启（默认开）
   - **用户名密码登录**：确认开启（默认开）
7. 「安全域名」→ 把游戏网址加进去（如 `你的用户名.github.io`），否则浏览器请求会被拒（报 permission_denied）
8. 重新构建部署（`npm run build`），完成

行为说明：

- 注册流程：邮箱+密码 → 收验证码 → 输码完成（CloudBase 强制邮箱验证）
- 未登录玩家也能提交分数和看排行榜（以"匿名玩家"身份、走匿名登录）
- 密钥留空 = 本地模式，一切功能正常，数据只存玩家本机
- 云端逻辑全部在 `src/services/backend.js` 一个文件里，以后要换服务商只改它

> 备选方案：玩家主要在海外可用 Supabase（免费额度大、10 分钟接完，但大陆访问不稳）；想完全自控可自建 PocketBase（单文件后端，需自购服务器+备案）。

### 手机号 / 微信登录（后置）

- **手机号短信登录**：CloudBase 支持（仅上海地域），但短信按条收费。等有推广活动再开。
- **微信登录**：网页版微信登录需要「微信开放平台」企业资质认证（个人不行）。做成小程序/小游戏后则免费自动登录（openid）。

## 为了传播，做小程序值不值？

目标是"方便传播"的话，按投入从小到大有三条路（不必做小游戏）：

### 路线 1：H5 网页直接分享（现在就能用，零成本）

把游戏链接发到微信群/朋友圈，微信内置浏览器直接玩。
- 现部署在 GitHub Pages，国内访问不稳，**换到腾讯云 COS/CDN 或 CloudBase 静态托管**（见 DEPLOYMENT.md）后微信内秒开
- 缺点：分享出去是普通链接卡片，无小程序码，域名可能被微信折叠提示"非官方网页"
- **适合：现阶段、小规模试玩和收集反馈**

### 路线 2：小程序 web-view 套壳（传播收益/投入比最高，但要企业主体）

小程序里嵌一个 web-view 直接加载现在的网页，改造量几天。
- 得到小程序的全部传播优势：**原生分享卡片、小程序码海报、搜一搜收录、扫码即玩、微信免注册登录**
- 硬门槛：**web-view 仅限企业/组织主体**（个人主体不行）。需要企业/个体户/学校等主体注册+认证（300 元/年），且所嵌域名要 ICP 备案
- 类目选"教育"，避开游戏类目的软著要求
- **适合：确定要正式推广、且能挂靠一个组织主体时**

### 路线 3：原生小程序重写（长期方案）

用 Taro（React 语法）把界面重写成小程序原生组件，d3 地图改 canvas。个人主体也能上架（教育类目），体验最好，但工作量以周计。
- **适合：产品验证成功之后**

> 三条路账号体系都通：已接的 CloudBase 即微信云开发同源，小程序内玩家用微信身份免注册登录，排行榜数据共用一套。
>
> 流程本身都不难：mp.weixin.qq.com 注册（个人免费）→ 微信开发者工具 → 提交审核（数小时~几天）→ 发布。难点只在上面各路线的技术改造和主体资质。

**建议顺序：先走路线 1 部署到国内 CDN 跑起来 → 有组织主体就上路线 2 → 火了再考虑路线 3。**
