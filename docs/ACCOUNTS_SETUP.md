# 账号 · 积分 · 排行榜 — 配置指南 ACCOUNTS_SETUP

## 现在就能用的（无需任何配置）

游戏已内置完整的积分和排行榜功能，**不配置任何东西也能玩**，只是数据存在玩家自己的浏览器里（本地模式）。

### 计分规则（来自建议.docx，改规则编辑 `src/utils/scoring.js`）

| 关卡 | 得分 |
|---|---|
| 选择题（答题/事件问答）| 答对一题 +20 |
| 填诗 | 每空答对 +10 |
| 数字华容道 | 满分 100，每过 1 秒 −1 |
| 出逃 | 满分 50，每过 1 秒 −1，被抓一次额外 −10 |
| 图片找点 | 满分 50，每过 1 秒 −1 |

- 单次游玩每一关只计一次分（重玩同一事件不重复得分）
- 顶栏实时显示本局积分
- 走完人物一生 → 结算总分，自动提交排行榜
- 选人页右上角：登录/注册、🏆 排行榜

## 开启云端账号（邮箱注册 + 全网排行榜）

用 LeanCloud（国内免费额度够用，个人可注册）。约 15 分钟：

1. 打开 <https://www.leancloud.cn>，注册开发者账号（要实名认证，个人身份即可）
2. 控制台 → 创建应用 → 选「开发版」（免费）
3. 应用 → 设置 → 应用凭证，找到三个值：**AppID**、**AppKey**、**REST API 服务器地址**
4. 粘贴进 `src/config/leancloud.js`：

```js
export const LEANCLOUD_CONFIG = {
  appId: "你的AppID",
  appKey: "你的AppKey",
  serverURL: "https://xxx.lc-cn-n1-shared.com",  // REST API 地址
};
```

5. LeanCloud 控制台 → 数据存储 → 结构化数据：无需手动建表，第一次提交分数会自动创建 `Score` 表
6. （上线后建议）控制台 → 数据存储 → 权限设置：把 `Score` 表的 delete/update 权限关掉，防止刷榜
7. 重新构建部署（`npm run build`），完成。玩家就能邮箱注册、上全网排行榜了

> 密钥填上后代码自动切换云端模式，什么都不用改。清空密钥即回到本地模式。

### 手机号 / 微信登录（后置）

- **手机号短信登录**：LeanCloud 支持，但短信按条收费，且要申请签名备案。等有推广活动再开。
- **微信登录**：网页版微信登录需要「微信开放平台」企业资质认证（个人不行）。如果以后做微信小游戏，小游戏内是免费自动登录的（见下）。

## 微信小游戏改造评估

结论：**能做，但是一次不小的改造，建议放最后。**

- 微信小游戏**不支持 DOM/HTML**，只有 canvas。本游戏是 React + DOM 写的，不能直接搬进去，UI 层基本要重写（或引入 kbone/Taro 这类适配层，对游戏类支持一般）
- 小游戏也**不允许用 web-view 套壳**（小程序可以，游戏类目不行）
- 上线需要：微信注册小游戏账号、软著或版号相关审核（教育类目相对宽松）、服务器域名备案
- **划算的路径**：先用现在的网页版跑活动（微信里可直接转发网页链接，体验已经不错）；如果验证了需求，再立项小游戏版，届时账号可直接用微信 openid 免注册登录
