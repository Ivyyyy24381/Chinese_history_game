## 重点做的三个（其余是打磨）

### 1. 九重天 `celestial_spheres`（1321）
已知问题，按优先级：
- **文案看不懂**。「违愿者」「行善求名者」「沉思者」「原动天」——10–14 岁读不出画面。
  每一重要换成一句**能看见的画面**（例：月亮天不写「誓愿没能守住的人」，
  写「被哥哥从修道院里抢走的修女」）。
- **太简单**。九个按顺序摆，环上还印着 1–9，等于数数。
  建议：卡片上**只给那句画面 + 星象符号，天名点亮后才揭晓**——更难、字更少、揭晓有奖励。
  再加一两个不属于九重天的干扰项（地狱 / 炼狱山），放错就是暗的。
- 当前 574 字，全线最重的一幕。目标砍到 200 以内。

### 2. 放逐循环 `trust_game`（1295）
- 图表配色是 dataviz 验证脚本过的暗色分类盘，**顺序不能动**（相邻对的色觉分辨度按那个序验的）。
- 文案必须跟模拟对齐。改策略/收益/代数之后要重跑：把 ScenePlayer 里
  `const SPARE` 到 `runCity` 抠成 .mjs，`node` 直接跑。实测分界见 DESIGN_VERBS。
- 视觉待办：满城那一幕现在很「仪表盘」。可以让六种人以小头像出现在城里，
  死掉的淡出——比纯柱状图更像一座城。

### 3. 安放三界 `inferno_placement`（1302）
- 现在四个人三个界，靠生平基本能推出来，**偏简单**。
- 建议加难度：补皮卡尔达（→天堂，科尔索和福雷塞的妹妹，多纳蒂三兄妹正好散在三界，
  cast.json 里已经有她了）；再加圭多·卡瓦尔坎蒂 + 第四个投放区「**不在书里**」——
  他 1300 年还活着，所以不可能出现在死后世界，但丁只让他父亲在《地狱》X 里问起他。
  这一问很难，而且教的是真东西。

## 视觉打磨队列（其余全部）

原则：**能画就别写。** 已经建好的两个工具：
- `src/data/icons.js` —— game-icons.net 的 SVG path，`<Icon name size color/>`，随 CSS 改色，
  不落文件不走 CDN。要新图标照文件顶部注释取。署名见 `CREDITS.md`。
- `predict_reveal` 支持 `option.image` + `caption` → 三张画面卡片；`mode:"gates"` → 两扇门走过去。
  **凡是纯文字多选题都该换掉。**

按值得做的顺序：
1. 各关收尾那些 6–10 行的大段文字（`coda` / `finale` / `conclusion`）→ 做成 3–5 个「节拍」：
   一个大字或年份 + ≤12 字。BioPanel 的生平段落同理（改成年份点的时间条，长文收进「详细」）。
2. `explore` 是全线最多的一类，仍然是「点人读字」。至少让 NPC 有个进场动作、被点过的有状态变化。
3. 声音已经有了（`playTone`，WebAudio 现合成，尊重全站 🎵 开关），
   目前只在九重天/出城/陈情用了。**所有拖放成功都该响一声。**
4. 公版图库：`CREDITS.md` 记了多雷 135 幅《神曲》版画等，**不用自己生成**。
   云端容器访问不到 Wikimedia / archive.org，本机可以，下到 `public/assets/dante/dore/`。

## 为什么本机更快

云端这边：代码在你的 Mac 上，但那边的 node_modules 是 darwin 二进制，
desktop 那个 shell 是 Linux VM 跑不了；所以每改一次视觉都要
`打包 → 上传云端 → npm build → Playwright 截图 → 我看 → 再改`，一轮好几个来回。

本机 Claude Code：`npm run dev` 原生跑，热更新，你自己浏览器里当场看见。
**视觉打磨这种要反复看的活，本机快一个数量级。** 内容和结构设计在哪边都一样。
