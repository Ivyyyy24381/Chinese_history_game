# 新人物开发 · Ray 交付清单（简明版）

> 一句话分工：**Ray 出内容（剧本 + 图），Claude/开发把内容变成游戏**（转 json、接引擎、调坐标、测试、上线）。
> 详细模版见 CHARACTER_TEMPLATE.md，这里只列"要交什么"。

## Ray 需要交的三样东西

### ① 事件清单（半页纸）

8–10 个关键年份事件，每个一行：**年份 · 地点 · 事件名 · 一句话说明这个事件负责人物弧线的哪一段**。
先把这份清单定稿，再动笔写剧本，避免返工。

### ② 剧本 SCREENPLAY（核心工作量）

照 `docs/CHARACTER_TEMPLATE.md` 的模版逐事件写，每个事件拆成若干 phase，**每个 phase 标注互动类型**：

| 类型 | 写什么 |
|---|---|
| explore 探索 | 场景描述 + 每个 NPC 的 2–3 句台词（谁是线索人物） |
| forced_choice 抉择 | 情境 + 问题 + 2–3 个选项及各自的回应文本 |
| exam 考题 | 选择题（4 选 1 + 解析）或补诗题（原句 + 3 个干扰项） |
| 数字华容道 | 要拼的原句（15 字）+ 限时 |
| 出逃 / 图片找点 / 连环画 | 玩法说明 + 相关台词/诗句（具体布点开发来做） |
| transition / narration 过场 | 旁白文字 |

**剧本阶段就要自查的三件事**（杜甫线踩过的坑）：
引用的诗句在该年份是否已写出来；行程路线是否合史实；台词是否符合人物当期思想、有无争议表述。

### ③ 图片资产

打开 `docs/ASSET_PROMPTS.md`，把**通用画风 prompt**（唐代工笔重彩）贴在每张图前面，批量生成：

- 事件背景图（每事件 3–6 张，16:9）
- NPC 立绘（每个有台词的角色一张，全身、透明底 PNG）
- 主角分期立绘（约 5 个时期 × 3 姿势）
- 大地图 + 路线图（可交给开发做）

文件命名照 ASSET_PROMPTS 清单，或者直接打包发来由开发归位。
（可选）BGM 每时期一首 mp3，命名 = stage id，放 `public/assets/audio/bgm/`。

## 交付方式

剧本（md/docx 都行）+ 图片包，直接丢给 Claude，并说明"做 XX 人物线"。
剩下的：timeline.json / event.json / quiz.json 转写、编辑器坐标微调、积分接入、通关测试、部署——都不用 Ray 管。
