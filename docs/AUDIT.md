## 三、E 项：UI 硬指标逐条

### ✅ 最小字号
全线 **117 处** `fontSize` 的 `clamp()` 下限低于 12px，最小的 7.2px。
全部抬到 12px（`clamp` 上限跟着抬，否则下限比上限大）。
**复测：0 处。**

### ✅ 键盘焦点
全站按钮几乎都是自绘 `<div>`，Tab 过去看不出焦点在哪。
`game.css` 加了一条 `:focus-visible` 金色描边（只在键盘导航时出现，
鼠标点击看不到），深色场景里再加一圈暗底。

### ✅ 触屏 / 键盘可达
新增 `pressable()` 助手，给 **14 处**「拖放的备选路径」和「唯一的前进方式」
补上 `role` / `tabIndex` / Enter-Space：九重天的轨道槽和天体卡、因果链、
contrapasso、时间轴、手稿、三界、挑证据、过场卡、连环画。
原来这些交互对键盘用户等于不存在。
**拖放的「先点 A 再点 B」备选路径全线都有**（逐个查过，没有漏的）。

### ✅ prefers-reduced-motion
查出 **9 个** phase 组件有动效但没读 `usePrefersReducedMotion`。
在 `game.css` 加了一条全局 `@media (prefers-reduced-motion: reduce)` 兜底，
`!important` 连内联 style 一起管；压到 `0.01ms` 而不是 `none`——有些逻辑挂在
`animationend`/`transitionend` 上，设 none 事件就不触发，界面会卡住。
**用 Playwright 的 `reducedMotion` 开关实测三幕**（九重天自转、连环画揭开、
三界投放高亮）：关闭时分别有 40 / 6 / 11 处仍在动，开启后**全部为 0**。

### 对比度：怎么量的
新增 `npm run contrast`。**从截图量像素，不查 CSS**——这个游戏的文字全压在
底图上，CSS 里查到的背景多半是 `transparent` 或一层半透明蒙版，算出来的数
跟眼睛看到的没关系。做法是把文字外框裁出来，**剔掉和文字同色的像素**
（那是字本身），剩下的按亮度取 10/90 百分位当背景明暗两端，两端都算一遍取更差的。

emoji（自带颜色，CSS `color` 不生效）、单字标签、小框三类量不准，单独报数交给肉眼。

修掉的两类系统性问题：
1. **explore 的叙述行**——顶带蒙版原来 `rgba(0,0,0,0.7) → transparent` 一路到底，
   等标题下面那行叙述出现时蒙版已经淡光了。1295 医药行会那关背景是一排彩窗，
   实测 **1.72:1**，右半句基本看不见。占不达标总数的近一半。
2. **禁用状态的按钮**——7 处都是 `opacity: 0.45`，压在深色场景上实测 **1.56:1**。

还有一条值得记下来的教训：我第一轮把 `#999` 一律提亮，结果补诗那块是**浅纸底**，
浅上加浅反而更看不见（1.69:1）。**同一个「弱化文字」颜色在深色场景和浅色纸面上
要反着调**，不能全局一刀切。

## 四、多语言

架构就是你定的那一套，现有数据文件**一个字没动**：

- `src/data/<line>/i18n/<lang>.json` —— 扁平 key→字符串，key 是 JSON 路径
- `src/i18n/ui.js` —— 组件里硬编码的 UI 文案，`{zh,en}` 形式
- `scripts/i18n_extract.mjs` —— `npm run i18n:extract`
- `useLang()` + `t()`，语言存 `localStorage.lishiyou_lang`，默认 zh
- 语言开关在主页标题下面
- 字体收进 CSS 变量 `--font-body`，`html[lang^="en"]` 换衬线栈（末尾仍留楷体，
  给回落成中文的那几句）

**关键决定**：翻译发生在**读取数据的那一刻**——深拷一份，逐个字符串按路径查字典，
查不到留中文。所以 `ScenePlayer` 那 5900 行渲染代码一行没改，也不会出现
「译了一半、某条渲染路径漏掉」。

覆盖率：**但丁线 1107/1107 = 100%**，**杜甫线 1084/1087 = 99.7%**，UI 文案 373 条全译。

剩下 3 条不译是有意的：`751_lifu` 那三副对句是让玩家一个字一个字拼出来的，
答案要和拼出的字串逐字相等，译成英文这个游戏就不成立。缺 key 自动回落中文，
那一关照常能玩。

三个新的自检命令：
```bash
npm run i18n:extract   # 抽取 + 填空题完整性校验
npm run i18n:ui        # 组件里每个 t(...) 都能查到吗（现在 0 处遗漏、0 处漏译）
npm run shots -- --lang en   # 整条线跑一遍，扫出「en 模式下仍在渲染中文」
```

最后那条是这轮最有用的工具：静态 grep 找不出写成模板字符串和 `\uXXXX` 转义的中文
（源码里有 **74 处**这种），只有把整条线在 en 模式下渲染出来扫一遍才找得到。
